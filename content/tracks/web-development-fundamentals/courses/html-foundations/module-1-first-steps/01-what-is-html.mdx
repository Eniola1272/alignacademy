# What is HTML?

<Hook>
Every website you've ever visited — Google, YouTube, Instagram — started as a simple text file. That text file was written in HTML. In the next 5 minutes, you'll write your first line of HTML and see it come alive in your browser.
</Hook>

## The Concept

**HTML** stands for **HyperText Markup Language**. It's the skeleton of every web page on the internet.

Think of building a house. Before you paint the walls or hang curtains, you need a **blueprint** — a plan that says where the walls go, where the doors are, and how big the windows should be. HTML is that blueprint for web pages. It tells the browser *where* to put things and *what* those things are.

When you open a website, your browser downloads an HTML file. It reads through the file, line by line, and **renders** (displays) it as the visual page you see. Text becomes readable. Headings become big and bold. Images appear in the right spots. All because of HTML.

One important thing: HTML is **not** a programming language. It doesn't do calculations or make decisions. It's a **markup language** — it *describes* and *structures* content. And that's perfectly fine! Every web page in the world needs it.

HTML was created by **Tim Berners-Lee** in 1991. Over 30 years later, it's still the foundation of the web. Pretty impressive for a simple text file.

## The Syntax

```html
<h1>Hello, World!</h1>
```

That's it. That's real HTML.

The `<h1>` part is called a **tag**. It tells the browser, "Hey, this text is a main heading — make it big and bold." The browser reads this line and displays the words **Hello, World!** as a large heading on the page. You'll learn more about tags in the next lesson.
