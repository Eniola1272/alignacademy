# Final Project: Style the Copywriter Landing Page

<Hook>

Now you combine **everything** to transform your plain HTML landing page into a polished, professional website that a freelance copywriter would be proud to show clients. ## The Concept

This lesson is a **guided build**. We're going to walk through the complete CSS needed to style Sarah Chen's landing page, section by section. You've already learned every concept we'll use — this is where it all clicks together.

Here's the game plan:

**1. Global Reset & Font** — We start with `box-sizing: border-box` on everything and set the Inter font. This gives us a clean, predictable foundation.

**2. Navigation** — Flexbox centers the links in a row. Uppercase text and letter-spacing give it a polished, professional feel. Hover effects add interactivity.

**3. Hero Header** — A dark gradient background (`#1a1a2e` to `#16213e`) creates a dramatic first impression. Large, bold text and a bright CTA button demand attention.

**4. About Section** — Flexbox places the image and text side-by-side. A `border-radius` on the image softens it.

**5. Services** — We remove default bullet points and add a colored left border to each list item. Clean and modern.

**6. Selected Work** — The ordered list gets breathing room, and the `<em>` results stand out in the accent color.

**7. Contact** — Centered text with a styled link.

**8. Footer** — Dark background mirrors the hero. Small, centered text.

**9. Responsive** — A media query stacks everything vertically on mobile, reduces font sizes, and makes images flexible.

The color scheme: **dark navy** (`#1a1a2e`) for the hero and footer, **white** for content sections, and a **warm pink accent** (`#f5576c`) for buttons and highlights. The Inter font keeps everything clean and modern.

**This is YOUR page.** You can change every color, every font size, every spacing decision. The goal is to have a **complete, working, responsive landing page** by the end of this lesson.

Here's the complete reference stylesheet. Read through it section by section — you'll recognize every property:

```css
/* ===========================
   GLOBAL RESET & TYPOGRAPHY
   =========================== */
* {
  margin: 0;
  padding: 0;
  box-sizing: border-box;
}

body {
  font-family: 'Inter', sans-serif;
  color: #333;
  line-height: 1.7;
}

/* ===========================
   NAVIGATION
   =========================== */
nav {
  display: flex;
  justify-content: center;
  gap: 32px;
  padding: 20px;
  background-color: #1a1a2e;
}

nav a {
  color: rgba(255, 255, 255, 0.7);
  text-decoration: none;
  text-transform: uppercase;
  font-size: 13px;
  font-weight: 600;
  letter-spacing: 2px;
  transition: color 0.3s ease;
}

nav a:hover {
  color: #ffffff;
}

/* ===========================
   HERO HEADER
   =========================== */
header {
  background: linear-gradient(135deg, #1a1a2e, #16213e);
  color: white;
  text-align: center;
  padding: 80px 20px;
}

header h1 {
  font-size: 56px;
  font-weight: 800;
  margin-bottom: 8px;
}

header p {
  font-size: 18px;
  color: rgba(255, 255, 255, 0.8);
  margin-bottom: 12px;
}

.cta-button {
  display: inline-block;
  background-color: #f5576c;
  color: white;
  padding: 14px 36px;
  border-radius: 8px;
  text-decoration: none;
  font-weight: 700;
  font-size: 16px;
  margin-top: 20px;
  transition: all 0.3s ease;
}

.cta-button:hover {
  background-color: #e0314b;
  box-shadow: 0 4px 20px rgba(245, 87, 108, 0.4);
  transform: scale(1.05);
}

/* ===========================
   CONTENT SECTIONS
   =========================== */
section {
  padding: 60px 20px;
  max-width: 800px;
  margin: 0 auto;
}

section h2 {
  font-size: 32px;
  font-weight: 700;
  margin-bottom: 24px;
  color: #1a1a2e;
}

/* ===========================
   ABOUT SECTION
   =========================== */
#about {
  display: flex;
  gap: 40px;
  align-items: center;
}

#about img {
  border-radius: 12px;
  width: 250px;
}

#about p {
  font-size: 17px;
}

/* ===========================
   SERVICES SECTION
   =========================== */
#services ul {
  list-style: none;
}

#services li {
  padding: 14px 20px;
  border-left: 4px solid #f5576c;
  margin-bottom: 12px;
  font-size: 17px;
  background-color: #fafafa;
  border-radius: 0 8px 8px 0;
}

/* ===========================
   SELECTED WORK SECTION
   =========================== */
#work ol {
  padding-left: 24px;
}

#work li {
  padding: 12px 0;
  font-size: 17px;
  line-height: 1.6;
}

#work em {
  color: #f5576c;
  font-weight: 600;
}

/* ===========================
   CONTACT SECTION
   =========================== */
#contact {
  text-align: center;
}

#contact a {
  color: #f5576c;
  font-weight: 600;
  transition: color 0.2s ease;
}

#contact a:hover {
  color: #e0314b;
}

/* ===========================
   FOOTER
   =========================== */
footer {
  background-color: #1a1a2e;
  color: rgba(255, 255, 255, 0.5);
  text-align: center;
  padding: 24px 20px;
  font-size: 14px;
}

/* ===========================
   RESPONSIVE — MOBILE
   =========================== */
@media (max-width: 768px) {
  header {
    padding: 50px 20px;
  }

  header h1 {
    font-size: 36px;
  }

  nav {
    flex-direction: column;
    align-items: center;
    gap: 12px;
  }

  #about {
    flex-direction: column;
    text-align: center;
  }

  #about img {
    width: 100%;
    max-width: 350px;
  }

  section {
    padding: 40px 20px;
  }
}
```

That's roughly **120 lines** of CSS — and you understand every single one. Colors, fonts, flexbox, hover effects, transitions, gradients, media queries. Everything from this course working together.
